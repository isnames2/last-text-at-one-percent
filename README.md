A make.fun entry for the "Last Text at One Percent" competition:
https://make.fun/bounty/u-azazex-last-text-at-one-percent-ba9fc876

`main.py` (pure Python standard library) writes one text message — the
last text a phone sends at one percent battery, in the phone's own voice —
to `$MAKEFUN_OUTPUT_DIR/entry.txt`. The output is deterministic and
byte-identical on every run.

> Battery at 1%. I survived 47 alarms you snoozed, so you're welcome.
> Tell the charger we had a good run. Goodbye, thumbs.
